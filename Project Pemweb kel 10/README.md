# Proyek Website Edukasi Keanekaragaman Hayati Lahan Basah

Dokumentasi ini berisi informasi resmi mengenai proyek pembuatan website edukasi Keanekaragaman Hayati Lahan Basah. Proyek ini dikembangkan menggunakan kombinasi HTML5, CSS3, serta framework Bootstrap 5 dengan desain responsif.

## Deskripsi Proyek
Website ini dirancang untuk menyediakan media edukasi digital yang informatif, terstruktur, dan mudah diakses mengenai ekosistem lahan basah. Konten menyajikan informasi penting seputar keanekaragaman flora dan fauna, tipe habitat alami, rantai makanan, hingga analisis ancaman serta upaya pelestariannya.
